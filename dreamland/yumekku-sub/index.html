ご利用の申請と、Yumekku Link の発行はこちらで承ります。

How it works

ご利用までの流れ

  1. ご利用を申請する
    ご契約時の合言葉・MT5 の口座番号・お名前を送ります。
  2. 運営が承認する
    承認されると、このページが自動で次へ進みます。
  3. Yumekku Link で MT5 とつなぐ
    Windows のパソコンで、Yumekku Link を開くだけで口座に紐づきます。

Yumekku【サブスク版】は、運営がご利用を承認しているあいだだけ新しい取引を行います。ご解約などで承認を止めると、新しい取引は止まります（お持ちのポジションは通常どおり決済されます）。

Application

ご利用の申請

お申し込みの前にお読みください
  • ご利用は、運営が承認しているあいだに限ります。承認の前と、承認を止めたあとは、新しい取引を行いません。
  • ご解約のお申し出があった場合は、運営が承認を止めます。
  • MT5 のパスワードは、このページでも Yumekku Link でも入力しません。
  • Yumekku【サブスク版】は将来の利益を約束するものではありません。お取引の判断と結果はご自身に帰属します。
